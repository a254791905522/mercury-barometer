# Mercury Barometer Release Package

App name: Mercury Barometer

Bundle ID: com.rosewood.mercurybarometer.game

Device support: iPhone only

Gameplay fact card:
- Core action: Read three classical mercury instruments and predict the weather to protect your village.
- Main puzzle: Combine barometer (hPa), thermometer (Celsius), and hygrometer (%RH) readings to forecast one of five weather types.
- Instrument system: Three classical instruments with smoothstep fill animations; some are hidden at later stations to raise difficulty.
- Progression: 50 contracts across five historic observation stations (Royal Society London, Alpine Monastery, North American Plains, Yangtze Observatory, Arctic Field Station).
- Monetization and network: offline, no ads, no in-app purchases, no account, no analytics, no tracking.
